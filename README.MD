### Welcome to the MemberPress Migration Toolkit GitHub Repository
Migrate your MemberPress members, subscriptions, levels, and content restrictions to Paid Memberships Pro with a guided step-by-step wizard.

For more information please visit [www.paidmembershipspro.com/add-ons/pmpro-memberpress-migration-toolkit-add-on/](https://www.paidmembershipspro.com/add-ons/pmpro-memberpress-migration-toolkit-add-on/)

## Installation ##
For detailed installation steps, visit the [documentation](https://www.paidmembershipspro.com/add-ons/pmpro-memberpress-migration-toolkit-add-on/) page.

1. Download the current development ZIP file directly: `https://github.com/strangerstudios/pmpro-memberpress-migration-toolkit/archive/dev.zip`

**Please ensure that once installing this version of the plugin to remove `-dev` from the plugin's folder name.**

## Contributing to MemberPress Migration Toolkit ##
We encourage and welcome any contribution to MemberPress Migration Toolkit. Please read the [guidelines for contributing](https://github.com/strangerstudios/paid-memberships-pro/blob/dev/.github/CONTRIBUTING.md) to this repository.

There are various **ways to the help development** of MemberPress Migration Toolkit:

1. Report [bugs/issues](https://github.com/strangerstudios/pmpro-memberpress-migration-toolkit/issues/new) on GitHub.
2. Work on any issues by submitting a Pull Request.

Here are some ways for **non-developers to contribute** to MemberPress Migration Toolkit:

1. Translate MemberPress Migration Toolkit into your own [language](https://www.paidmembershipspro.com/paid-memberships-pro-in-your-language/).
2. [Purchase a paid membership](https://paidmembershipspro.com/pricing) to help fund ongoing development and bug fixes.
3. Leave an honest review for [Paid Memberships Pro - MemberPress Migration Toolkit](https://www.paidmembershipspro.com/submit-testimonial/).
